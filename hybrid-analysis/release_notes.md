#### Following enhancements have been made to the Hybrid Analysis Connector in version 2.1.0:

- Added a new action `Quick Scan by ID` and its associated playbook.
- Renamed the action and playbook label from `Get Analysis Report for Multiple Hashcodes` to `Get Analysis Report for HashCode`.
    - Renamed the parameter `Hash Codes` to `Hash Code` for this action.
    - Updated the output schema for this action.
